# 🧠 IconsDrop Memory Game

A modern memory matching game created to showcase the premium 3D icon collections from IconsDrop.

## 🎮 Play

Match all pairs of icons and achieve the highest score!

## ✨ Features

- Modern and minimalist interface
- Premium 3D Icons
- Timer
- Score system
- Combo multiplier
- Responsive design
- Sound effects
